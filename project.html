Desctiption

바닐라 자바스크립트를 기반으로 Three.js를 활용해 3D 모델을 로드하여 애니메이션을 구현, 각 섹션 별 GSAP ScrollTrigger 애니메이션을 구현한 인터랙티브 포트폴리오 사이트입니다. 반응형 디자인은 물론 타임라인 기반의 모션 컨트롤을 디테일하게 구현하였습니다.

Technologies & Tools

  • GSAP
  • Three.js
  • CSS Transition
  • Responsive Design

Function Descrilition

  • GLB 형식의 3D 모델을 Three.js로 렌더링 후 스크롤에 따른 인터랙티브 애니메이션 구현
  • 각 섹션 맞춤 GSAP 타임라인 애니메이션과 ScrollTrigger를 연동하여 자연스러운 애니메이션 흐름 연출
  • 다양한 화면 크기에 대응할 수 있도록 반응형 인터랙션 설계

Trouble Shootings

재로딩 시 3D 모델이 보이지 않는 문제
문제
새로고침 시 GLTFLoader의 비동기 로딩이 끝나기 전에 3D 모델 인트로 애니메이션인 gsap.to(model.scale)이 실행되어 undefined.scale 오류 발생
해결 방법
  • GLTFLoader를 Promise로 감싸 await 기반으로 모델 로드 완료 후 애니메이션 실행
  • 기존 GSAP 타임라인 안에서 .call(() => loadModelsAndAnimate())로 정확한 실행 타이밍 제어
  • 모델 수가 많아져도 대응 가능하도록 Promise.all()을 통한 병렬 로딩 구조로 확장 가능
